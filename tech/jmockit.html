JMockit

Java testing toolkit that can mock static methods, constructors and final classes.

How it works

  1. Mock static, final or constructor
  2. Expectations block
  3. Run code under test
  4. Verifications block

Capabilities

  • Mocking of static methods, constructors and final classes
  • Expectation-based and verification-based tests
  • Works with JUnit and TestNG
  • Partial mocking of real objects

Where I used it

  • Kuehne+Nagel (2018 - now): JMockit unit tests
