EasyMock

Mock object library for Java with a record, replay and verify workflow.

How it works

  1. createMock()
  2. Record expectations
  3. replay()
  4. Run code under test
  5. verify()

Capabilities

  • Record expected calls, replay them and verify
  • Strict and nice mocks
  • Argument matchers
  • Works with JUnit

Where I used it

  • Kuehne+Nagel (2018 - now): EasyMock unit tests
