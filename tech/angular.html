Angular JS

Front-end framework for single-page web applications, covering AngularJS (1.x) and Angular (2+).

How it works

  1. Template
  2. Component
  3. Service
  4. HTTP client
  5. REST API

Capabilities

  • Component-based UI with templates and data binding
  • Dependency injection
  • Routing and forms
  • HTTP client for REST calls
  • Unit tests with Jasmine and Karma

Where I used it

  • Kuehne+Nagel (2018 - now): front-end for iOPM
