Kuehne+Nagel

Java vanemarendaja · mai 2018 – praegu · Tallinn, Eesti

  • Ehitan sündmuspõhiseid liidestusi Apache Kafka (Spring Kafka tootjad/tarbijad, partitsioneerimine, võtmepõhine järjekord, nihete/tasakaalustamise haldus, Schema Registry, Kafka Streams/Connect) ja RabbitMQ abil.

Valitud iseseisvad projektid

EntityLocker

Java · JVM-i rööptöötlus

Java katse sama olemi võtit kasutavate lõimede tegevuse koordineerimiseks. Avalikud JUniti testid hõlmavad pesastatud lukustamist, luku kordushõivamist sama lõime poolt ja ooteaja lõppemist. Juhtumianalüüs käsitleb, miks lukuobjektide ohutu eemaldamine vajab eraldi kontrollimist.

Igal eksemplaril on oma lukuregister. Kirjeldus eristab ühe Java protsessi sisest lukustamist eri protsesside vahelisest koordineerimisest.

Sõnumiarhiiv ja semantiline otsing

Rust ja Python · PostgreSQL ja Qdrant

Iseseisev Rusti ja Pythoni projekt, mis transkribeerib heli ja indekseerib sõnumeid semantilise otsingu jaoks MCP kaudu. Indekseerija kirjutab stabiilse vektori ID-ga enne edenemispunkti nihutamist, et katkenud tööd saaks korrata.

PostgreSQL-i realukud võimaldavad tööprotsessidel jätta vahele ülesanded, mille mõni teine tööprotsess on võtnud. Korduv kirjutus uuendab sama vektorit. Muude kõrvaltoimete jaoks tuleb eraldi määrata korduskatsete reeglid.

Loe sõnumiarhiivi juhtumianalüüsi

FunnyFileManager

Rust · Terminaliliidesed ja failisüsteemi toimingud

Rustis kirjutatud terminali failihaldur kahe paneeli ja klaviatuurilt juhitavate failitoimingutega. Sisseehitatud redaktor kuvab kursori all oleva sümboli kohta keeleserveri infot.

Avalikus repositooriumis on käitumistestid redaktoris otsimise ja salvestamise, kiirotsingu ning levinud failitoimingute jaoks.

Vaata repositooriumi ja teste · Lähtekood GitHubis

RustShot

Rust · Töölaua jäädvustamine ja platvormiadapterid

Rustis kirjutatud kuvatõmmiste tööriist Windowsile, Linuxile ja macOS-ile. Platvormiadapterid kasutavad ühist väljundi käsitlemise loogikat. Jäädvustamisjuhendis on kirjeldatud iga operatsioonisüsteemi toetatud režiimid ja väljundi sihtkohad.

Waylandis jäädvustab kogu töölaua töölauaportaal. Windowsis on ekraanisalvestuseks eraldi töövoog.
