Avatud lähtekoodiga Java projekt · github.com/stden/EntityLocker

EntityLocker — olemipõhine Java lukustusvahend

Probleem: Uurida, kuidas Java lõimed saavad ühes protsessis olemi võtme alusel oma tööd koordineerida.

Arhitektuur: Lõimekindel kujutus seob olemitunnused taassisenemist lubavate lukkudega. Lõimekohane väärtus jälgib lukustamise järjekorda ja lükkab pesastatud väiksema tunnuse tagasi. Kriitilisest sektsioonist väljudes püütakse registrikirje eemaldada.

Tehnoloogiad: Java, ConcurrentHashMap, ReentrantLock, JUnit

Iseseisev isiklik projekt

Sõnumiarhiiv ja semantiline otsing

Probleem: Leida privaatsest sõnumiarhiivist teksti ja transkribeeritud heli tähenduse järgi.

Arhitektuur: Rusti teenus loeb sõnumeid MTProto kaudu. PostgreSQL talletab sõnumid ja transkribeerimistööd. Pythoni tööprotsess käivitab Whisperi ning Rusti indekseerija salvestab tekstivektorid Qdranti. Otsing on kättesaadav MCP-liidese kaudu.

Tehnoloogiad: Rust, Python, MTProto, PostgreSQL, Whisper, Qdrant, MCP
