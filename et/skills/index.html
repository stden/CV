Oskused ja nende rakendamine

Java, hajussüsteemid, iseseisev inseneritöö ja näited CV-s nimetatud tehnoloogiate kasutamisest.

Põhipädevused

Peamised inseneripädevused

Taustasüsteemid, asünkroonne integratsioon ja tootmiskeskkonna töökindlus ettevõtte Java platvormil ja mitme programmeerimiskeele tööriistadega.

Java ja JVM

Arendab Spring Booti teenuseid. Oracle’i töökogemus hõlmab JVM-i lõimede samaaegset tööd, klasside laadimist ja JDK testimist.

Hajussüsteemid

Arendab asünkroonseid taustateenuseid ja hajuskeskkondade automaatteste. Iseseisvates projektides uurib korduskatseid ja töötluse ohutut kordamist.

Sündmuspõhine arhitektuur

Arendab Apache Kafka ja Spring Kafka abil tootmiskeskkonnas töötavaid sündmuspõhiseid teenuseid.

Ettevõttesüsteemide liidestamine

Arendab Java, XML-i ja relatsioonandmebaaside abil taustasüsteemide liidestusi.

Pilveteenused ja taristu

Automatiseerib tarkvara koostamist ja juurutamist Jenkinsi, GitLab CI/CD ja konteineritööriistadega.

Tarkvara kvaliteet ja töökindlus

Uurib testide tõrkeid, parandab automaattestide katvust ja stabiliseerib Java testikomplekte.

Tehisintellekt ja automatiseerimine

Iseseisvates projektides kasutab transkribeerimiseks, semantiliseks otsinguks ja tehisintellekti tööriistade loomiseks Rusti, Pythonit ja MCP-d.
