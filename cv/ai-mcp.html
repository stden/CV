Selected Projects

Personal engineering project (independent of employer work)

Messenger Archive & Semantic Search

Problem: Long-running personal chat archives mix text and voice messages across thousands of threads, making keyword lookup ineffective for finding past discussions or feeding context to LLM agents.

Architecture: A Rust sync service pulls history via MTProto with flood-wait backoff into PostgreSQL. A Python worker claims pending voice rows using PostgreSQL SKIP LOCKED and transcribes them with Whisper. A Rust indexer generates batched local embeddings and upserts points into Qdrant, exposed to LLM agents via an MCP server (stdio and HTTP).

Stack: Rust, Python, PostgreSQL (SKIP LOCKED), Whisper, Qdrant, MCP

Employer project · Kuehne+Nagel

XML Transformation Pipeline

Problem: Upstream enterprise systems send diverse XML payloads over AMQP that require routing, custom XSLT transformations with Java extensions, and hot-deployable rule updates without service restarts.

Architecture: Upstream systems publish XML messages to a RabbitMQ request queue consumed by a bounded worker pool. A Router resolves target out-queues, a Saxon XSLT transformer applies cached stylesheets backed by Java extension functions loaded from plugin jars, and transformed payloads are delivered to destination queues.

Stack: Java, Spring AMQP, RabbitMQ, Saxon XSLT, JDBC
