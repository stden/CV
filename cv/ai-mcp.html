Selected Projects

Independent personal project

Messenger Archive & Semantic Search

Problem: Long-running personal chat archives combine text and voice messages across thousands of threads, making keyword search ineffective for recalling context or supplying structured history to LLM agents.

Architecture: A Rust sync service fetches personal chat history over MTProto with flood-wait backoff into PostgreSQL. A Python worker claims pending voice rows using PostgreSQL FOR UPDATE SKIP LOCKED (row-level locking that skips already locked rows) and transcribes them with Whisper. A Rust indexer computes batched local embeddings and upserts points into Qdrant, exposed to LLM agents via a read-only MCP server (stdio and HTTP).

Stack: Rust, Python, PostgreSQL (FOR UPDATE SKIP LOCKED), Whisper, Qdrant, MCP

Open-source Rust projects · github.com/stden

FunnyFileManager & RustShot — Systems & Desktop Tooling

Problem: Building responsive cross-platform developer utilities—a keyboard-driven dual-panel terminal file manager and a fast screen-capture/recording utility—with automated tests and release pipelines.

Architecture: FunnyFileManager uses Rust and ratatui for a dual-panel terminal UI with background LSP diagnostics and S3 drive entries. RustShot uses Rust for instant screenshot capture on Windows and Linux (X11/Wayland portal) plus H.264 MP4 recording on Windows.

Stack: Rust, ratatui, Gherkin BDD, GitHub Actions
