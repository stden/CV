Selected Projects

Open-source Java project · github.com/stden/EntityLocker

EntityLocker — Row-Level Entity Concurrency Utility

Problem: Explore how Java threads can coordinate by an entity key within one process.

Architecture: A concurrent map associates entity IDs with reentrant lock objects. A thread-local value records the current acquisition order and rejects a lower nested ID. Registry removal is attempted when a critical section exits.

Stack: Java, ConcurrentHashMap, ReentrantLock, JUnit

Independent personal project

Messenger Archive & Semantic Search

Problem: Search text and transcribed audio by meaning in a private message archive.

Architecture: Rust loads message records through MTProto. PostgreSQL stores records and transcription jobs. A Python worker runs Whisper, and a Rust indexer stores embeddings in Qdrant. An MCP interface exposes search.

Stack: Rust, Python, MTProto, PostgreSQL, Whisper, Qdrant, MCP
