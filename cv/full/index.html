Secure Document Link Gateway

Kuehne+Nagel, iOPM (work)

Time-limited, encrypted links to documents stored on a remote system.

Stack: Java 17, Spring Boot, PostgreSQL, AES-GCM

  • Each link carries its own expiry and is AES-GCM encrypted, so the gateway can serve files without a database lookup.
  • Background jobs, not request handlers, fetch documents and remove expired files.

XML Transformation Pipeline

Kuehne+Nagel, iOPM (work)

Asynchronous XML routing and XSLT transformation with Java extension functions loaded from plugins.

Stack: Java, Spring AMQP, RabbitMQ, Saxon XSLT, JDBC

  • Each plugin jar gets its own classloader, so plugins can be replaced and the context reloaded without restarting the service.
  • Routing and transformation are separate steps, so each can change on its own.

Messenger Archive & Semantic Search

Personal project

A searchable archive of a personal messenger history, with voice messages transcribed and indexed, exposed to LLM agents through an MCP server.

Stack: Rust, Python, MTProto, Whisper, PostgreSQL, Qdrant, MCP

  • Writes are idempotent: deterministic UUIDv5 point IDs, and the cursor is saved only after each upsert.
  • Transcription workers claim queue rows with SKIP LOCKED, so several workers can run in parallel.
