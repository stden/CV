Selected Projects

Open-source Java project · github.com/stden/EntityLocker

EntityLocker — Row-Level Entity Concurrency Utility

Problem: Applications caching or mutating domain entities concurrently often face either coarse global locks that bottleneck throughput or complex ad-hoc per-key lock maps prone to leaks and races.

Architecture: A generic EntityLocker<ID> coordinator manages per-entity-ID mutual exclusion without coupling to entity payload types, supporting different ID types, reentrant locking semantics, escalation/global locking options, and bounded cleanup of unused lock entries.

Stack: Java, java.util.concurrent, ConcurrentHashMap, ReentrantLock

Independent personal project

Messenger Archive & Semantic Search

Problem: Long-running personal chat archives combine text and voice messages across thousands of threads, making keyword search ineffective for recalling context or supplying structured history to LLM agents.

Architecture: A Rust sync service fetches personal chat history over MTProto with flood-wait backoff into PostgreSQL. A Python worker claims pending voice rows using PostgreSQL SKIP LOCKED and transcribes them with Whisper. A Rust indexer computes batched local embeddings and upserts points into Qdrant, exposed to LLM agents via a read-only MCP server (stdio and HTTP).

Stack: Rust, Python, PostgreSQL (SKIP LOCKED), Whisper, Qdrant, MCP
