Ausgewählte eigenständige Projekte

EntityLocker

Java · Nebenläufigkeit in der JVM

Ein Java-Experiment zur Koordination von Threads, die denselben Entitätsschlüssel verwenden. Die öffentlichen JUnit-Tests decken verschachtelten Sperrerwerb, Reentranz und Zeitüberschreitungen ab. Die Fallstudie erläutert, warum das sichere Entfernen von Sperrobjekten gesondert geprüft werden muss.

Jede Instanz hat eine eigene Sperr-Registry. Der Entwurf unterscheidet Sperren innerhalb eines Java-Prozesses von der Koordination zwischen Prozessen.

Fallstudie zu Entitätssperren lesen · Quellcode auf GitHub

Nachrichtenarchiv und semantische Suche

Rust und Python · PostgreSQL und Qdrant

Ein eigenständiges Projekt in Rust und Python, das Audio transkribiert und Nachrichten für die semantische Suche über MCP indexiert. Der Indexer schreibt unter einer stabilen Vektor-ID, bevor er den Fortschrittsmarker verschiebt. So lassen sich unterbrochene Schreibvorgänge wiederholen.

Mit PostgreSQL-Zeilensperren überspringen Worker bereits übernommene Aufträge. Ein erneuter Schreibvorgang aktualisiert denselben Vektor. Andere Seiteneffekte brauchen eigene Regeln für Wiederholungen.

Fallstudie zum Nachrichtenarchiv lesen

FunnyFileManager

Rust · Terminal-Oberflächen und Dateioperationen

Terminal-Dateimanager in Rust mit Zweifenster-Navigation und Tastatursteuerung für Dateioperationen. Der integrierte Editor zeigt Sprachserver-Hinweise zum Code an.

Das öffentliche Repository enthält Verhaltenstests zur Suche und zum Speichern im Editor, zur Schnellsuche und zu gängigen Dateioperationen.

Repository und Tests ansehen · Quellcode auf GitHub

RustShot

Rust · Desktop-Aufnahmen und Plattformadapter

Screenshot-Werkzeug in Rust für Windows, Linux und macOS. Plattformspezifische Adapter teilen die Ausgabelogik. Die Anleitung dokumentiert die unterstützten Aufnahmemodi und Ausgabeziele je Betriebssystem.

Unter Wayland erfasst das Desktop-Portal den gesamten Bildschirm. Windows unterstützt Bildschirmaufzeichnungen über einen eigenen Aufnahmepfad.
