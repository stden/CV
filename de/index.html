Ausgewählte Projekte

Eigenständige Arbeit in Java, Rust und Python. Die Repositories sind öffentlich; Fallstudien und Architekturdiagramme finden Sie auf den Seiten Projekte und Architektur. Jede Karte zeigt den Technologie-Stack und den CI-Status.

pythorust_tg

Rust-basiertes Werkzeugpaket zur Telegram-Automatisierung: Chat-Export, KI-Autoresponder, Indexierer und Betriebshilfen mit Prometheus-Metriken. Enthält außerdem Hilfen für HTTP-Benchmarks und Website-Monitoring.

Tastaturgesteuerter, zweispaltiger Terminal-Dateimanager in Rust, mit der Bibliothek ratatui entwickelt und inspiriert von Far Manager und Norton Commander.

Rust · Stack: Rust, ratatui · CI: CI passing

SonarQubeChecker

Kommandozeilenwerkzeug in Python, das SonarQube-Analysedaten und Probleme abruft und zweisprachige Markdown-Qualitätsberichte erstellt.

Python · Stack: Python, SonarQube API, Markdown reports · CI: test passing

EntityLocker

Wiederverwendbares Java-Werkzeug, das Aufrufern exklusiven Zugriff auf eine Entität je ID gewährt, ähnlich einer Zeilensperre in Datenbanken. Basiert auf wiedereintrittsfähigen Sperren, unterstützt Zeitlimits und verhindert Deadlocks bei geordnetem Sperren.

Java · Stack: Java, Maven, JUnit · CI: No CI workflow
