Старший инженер-программист | Java, распределённые системы и ИИ

Старший инженер-программист, специализируется на backend-разработке на Java, распределённых системах, событийно-ориентированной архитектуре, интеграции корпоративных систем и надёжности в продуктивной среде. Опыт работы в Kuehne+Nagel, Oracle и Taxify (Bolt), дополнен самостоятельными открытыми проектами на Python, Rust, в семантическом поиске и инструментах инженерии ИИ.

Более десяти лет разработки на Java: от корпоративных backend-систем до инженерии качества на уровне Java Core. Текущий фокус — надёжные распределённые сервисы: повторно безопасная обработка, управление конкурентностью и автоматизированное тестирование. Недавние самостоятельные работы включают утилиту конкурентности для Java, инструментарий автоматизации на Rust и конвейер семантического поиска по личному архиву мессенджера.

Языки: Русский (родной), Английский (средний)

Избранные проекты

Самостоятельные работы на Java, Rust и Python. Репозитории открыты; кейсы и архитектурные диаграммы — на страницах проектов и архитектуры. На каждой карточке указаны стек и статус CI.

pythorust_tg

Набор инструментов для автоматизации Telegram на Rust: экспорт чатов, ИИ-автоответчик, индексатор и служебные инструменты с метриками Prometheus. Включает также средства HTTP-бенчмарка и мониторинга сайтов.

Rust · Стек: Rust, Python, Prometheus, Telegram API · CI: CI/CD passing

FunnyFileManager

Двухпанельный файловый менеджер для терминала на Rust, управляемый с клавиатуры, построен на ratatui и вдохновлён Far Manager и Norton Commander.

Rust · Стек: Rust, ratatui · CI: CI passing

SonarQubeChecker

Инструмент командной строки на Python: получает данные анализа и проблемы SonarQube и создаёт двуязычные отчёты о качестве в Markdown.

Python · Стек: Python, SonarQube API, Markdown reports · CI: test passing

EntityLocker

Переиспользуемая Java-утилита, которая даёт вызывающему коду эксклюзивный доступ к одной сущности по её ID, аналогично блокировке строки в базе данных. Основана на реентерабельных блокировках, поддерживает тайм-ауты и предотвращает взаимные блокировки при упорядоченном захвате.

Java · Стек: Java, Maven, JUnit · CI: No CI workflow
