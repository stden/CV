Избранные независимые проекты

EntityLocker

Java · Многопоточность JVM

Эксперимент на Java: координация потоков по общему ключу сущности. Публичные тесты JUnit проверяют вложенный захват, повторный вход и тайм-ауты. В разборе показано, почему безопасное удаление объектов блокировок нужно проверять отдельно.

У каждого экземпляра собственный реестр блокировок. В описании проекта разграничены блокировки внутри Java-процесса и координация между процессами.

Архив сообщений и семантический поиск

Rust и Python · PostgreSQL и Qdrant

Независимый проект на Rust и Python расшифровывает аудио и индексирует сообщения для семантического поиска через MCP. Индексатор записывает вектор со стабильным ID до обновления контрольной точки, чтобы прерванную работу можно было повторить.

Блокировки строк PostgreSQL позволяют пропускать задания, которые забрал другой обработчик. Повторная запись обновляет тот же вектор, а для других эффектов нужны свои правила повторов.

FunnyFileManager

Rust · Терминальные интерфейсы и файловые операции

Терминальный файловый менеджер на Rust с двумя панелями и управлением операциями с клавиатуры. Во встроенном редакторе есть подсказки языкового сервера.

В публичном репозитории есть тесты поиска и сохранения в редакторе, быстрого поиска и типовых файловых операций.

Открыть репозиторий и тесты · Исходный код на GitHub

RustShot

Rust · Захват экрана и платформенные адаптеры

Утилита создания снимков экрана на Rust для Windows, Linux и macOS. Платформенные адаптеры используют общую обработку результата. Руководство описывает режимы и варианты вывода для каждой ОС.

На Wayland захват всего рабочего стола выполняет системный портал. В Windows запись экрана доступна как отдельный режим.
