Навыки и примеры применения

Java, распределённые системы, независимые инженерные проекты и примеры применения технологий из резюме.

Основные компетенции

Ключевые инженерные компетенции

Бэкенд, асинхронные интеграции и надёжность в эксплуатации. В основе корпоративная Java и инструменты на разных языках.

Java и JVM

Разрабатываю сервисы на Spring Boot. Опыт работы в Oracle включает многопоточность в JVM, загрузку классов и тестирование JDK.

Распределённые системы

Разрабатываю асинхронные бэкенд-сервисы и автотесты для распределённых сред. В независимых проектах исследую повторы и безопасную повторную обработку.

Событийная архитектура

Разрабатываю событийные сервисы на Apache Kafka (Spring Kafka, партиционирование, порядок по ключу, offsets/rebalancing, transactional outbox, идемпотентность, retry/DLQ, Schema Registry, Kafka Streams/Connect, мониторинг consumer lag) и RabbitMQ.

Корпоративные интеграции

Разрабатываю бэкенд-интеграции на Java с XML и реляционными базами данных.

Облако и инфраструктура

Автоматизирую сборки и развёртывания с Jenkins, GitLab CI/CD и контейнерными инструментами.

Качество и надёжность ПО

Исследую сбои тестов, расширяю автоматическое покрытие и повышаю стабильность тестовых наборов Java.

ИИ и автоматизация

В независимых проектах использую Rust, Python и MCP для транскрибации, семантического поиска и разработки инструментов с ИИ.
