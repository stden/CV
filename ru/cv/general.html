Избранные проекты

Открытый Java-проект · github.com/stden/EntityLocker

EntityLocker — утилита для блокировки отдельных сущностей

Задача: Исследовать, как потоки Java могут координироваться по ключу сущности в одном процессе.

Архитектура: Потокобезопасная карта связывает идентификаторы сущностей с реентерабельными блокировками. Локальное значение потока фиксирует порядок захвата и отклоняет меньший вложенный идентификатор. При выходе из критической секции утилита пытается удалить запись из реестра.

Стек: Java, ConcurrentHashMap, ReentrantLock, JUnit

Независимый личный проект

Архив сообщений и семантический поиск

Задача: Поиск по смыслу в текстах и расшифровках аудио из личного архива сообщений.

Архитектура: Сервис на Rust загружает записи сообщений через MTProto. PostgreSQL хранит записи и задания на транскрибацию. Обработчик на Python запускает Whisper, а индексатор на Rust сохраняет векторные представления в Qdrant. Поиск доступен через MCP.

Стек: Rust, Python, MTProto, PostgreSQL, Whisper, Qdrant, MCP
