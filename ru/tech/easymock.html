EA

EasyMock

Библиотека мок-объектов для Java с циклом записи, воспроизведения и проверки.

Как работает технология

  1. createMock()
  2. Записать ожидаемые вызовы
  3. replay()
  4. Запустить тестируемый код
  5. verify()

Инженерные возможности

  • Запись, воспроизведение и проверка ожидаемых вызовов
  • Строгие и мягкие мок-объекты
  • Сопоставление аргументов
  • Интеграция с JUnit

Где применялось

  • Дополнительный опыт тестирования Java
